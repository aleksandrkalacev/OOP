# Модуль «Тарифы и абонементы» (Лабораторная работа)

Программа представляет собой консольный терминал для управления абонементами клиентов фитнес-клуба. Разработана на языке **Java** с использованием принципов ООП.

## Архитектура проекта

Код разбит на независимые файлы и организован по структуре:

*   **`Main.java`** — управление программой, консольное меню и перехват исключений.
*   **`Client.java`** — модель данных клиента, хранит баланс и историю операций.
*   **`Subscription.java`** — бизнес-логика абонемента (проверка активности, расчет возврата и смены тарифов).
*   **`Tarif.java`** — перечисление тарифов (`enum`) с абстрактным методом для расчета цены периода.
*   **`Frozen.java`** — фиксация временных диапазонов заморозки подписки.
*   **`InsufficientFundsException.java`** — файл с кастомными исключениями бизнес-логики.
*   **`SubscriptionTest.java`** — 16 автоматических модульных тестов для проверки пограничных и не пограничных сценариев.

## Реализованный функционал

### Базовый уровень
*   Регистрация пользователя в системе при старте.
*   Покупка и продление тарифов с проверкой баланса.
*   Заморозка абонемента на N дней со сдвигом даты окончания.
*   Проверка активности подписки на текущую дату.
*   Выброс и обработка кастомных ошибок (нет денег, просрочено, заморожено).

### Повышенный уровень
*   Смена тарифа в середине периода с автоматическим перерасчетом доплаты/возврата.
*   Досрочный отказ от подписки с пропорциональным возвратом копеек на баланс.
*   Формирование хронологического отчета по операциям клиента.

## Ключевые акценты (по ТЗ)
1.  **Точные финансы**: Все расчеты денег ведутся строго через `BigDecimal`.
2.  **Полиморфизм в Enum**: Логика стоимости инкапсулирована внутри констант `Tarif` через абстрактный метод.
3.  **Работа со временем**: Использованы современные структуры `java.time.LocalDate` и `java.time.Period`.
